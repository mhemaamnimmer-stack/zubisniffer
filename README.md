# ZubiSniffer

**ZubiSniffer** is a customized desktop packet/session sniffer focused on live endpoint visibility, manual IP organization, and a fast native Qt interface.

> This repository is a derivative of [BUZZARDGTA/Session-Sniffer](https://github.com/BUZZARDGTA/Session-Sniffer) and remains licensed under GPL-3.0.

## Project goals
- Native desktop UI — no webview rewrite
- Real packet/session capture
- Manual-only IP Vault and list classification
- Clear endpoint/provider/session visibility
- Persistent user settings
- Custom ZubiSniffer visual system
- Maintainable source with upstream credit preserved

## Source
The repository bootstrap imports the full upstream source tree, including required resources, then keeps ZubiSniffer-specific project files and credits.
